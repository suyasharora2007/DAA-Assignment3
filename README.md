# DAA Assignment 3 — Graphs

Java 17 / Maven project implementing the graph algorithms required by Assignment 3.

## Implemented

- Adjacency-list `Graph` supporting directed and undirected graphs.
- Text-file graph loader.
- DSU with union by size and path compression.
- Kruskal minimum spanning forest.
- Prim minimum spanning forest using `PriorityQueue`.
- Iterative Kosaraju SCC with explicit-stack `maxDepth` metric.
- Kahn topological ordering with cycle detection.
- DAG shortest paths with a virtual super-source, negative weights, and path restoration.
- Deterministic benchmark generator matching the assignment's `Random(42)` procedure.
- Operation counters and automatic reference-value checks.

## Data

`data/connected.txt`, `data/disconnected.txt`, and `data/cyclic.txt` are the required small input graphs.

## Build and test

```bash
mvn clean test
```

## Run benchmark

```bash
mvn -q -Dexec.mainClass=daa.benchmark.BenchmarkRunner exec:java
```

or, after compilation:

```bash
java -Xmx3g -cp target/classes daa.benchmark.BenchmarkRunner
```

The benchmark writes 50 rows to:

- `results/results.csv` — assignment deliverable
- `results/benchmark.csv` — compatibility copy

The benchmark uses five runs and records the median wall-clock time. It also checks the assignment reference values, MST agreement, DAG acyclicity/topological validity, and required scan counts. A mismatch throws an exception instead of silently producing a CSV.

## Plots

The three required PNG charts are generated by:

```bash
python scripts/plot_results.py
```

They are stored in `results/plots/`.
